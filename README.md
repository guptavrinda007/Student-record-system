# Student Data & Performance Management System (C++)

A command-line C++ application built using Object-Oriented Programming (OOP) principles and file handling to record, query, and compute student GPAs.

## Key Features
* Add and update student records.
* Automatic 10-point scale GPA calculation.
* Permanent file storage using C++ File I/O (`students.txt`).
* Fast record retrieval with structured search.

## Tech Stack
* Language: C++
* Tools: VS Code, GCC Compiler

## How to Run Locally
1. Clone the repository:
   git clone https://github.com/guptavrinda007/student-record-management-cpp.git
2. Navigate to directory:
   cd student-record-management-cpp
3. Compile the code:
   g++ main.cpp -o student_system
4. Run executable:
   ./student_system
